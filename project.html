HTML & CSS

FORMA Web Layout

FORMA is a responsive one-page website built with HTML, CSS, and JavaScript based on a Figma AI-generated mockup. Created as a front-end practice project, it focuses on translating design into code while strengthening layout fundamentals, particularly CSS Grid and responsive design. Git was used for version control, and the project is deployed on Vercel. The website currently serves as a static landing page, with functionality limited to the navigation menu.

Expeculiart (Remake)

Expeculiart is a responsive front-end website built with HTML and CSS, inspired by a friend's business. Originally developed as a sophomore-year college project, it has been completely rebuilt from scratch using the skills and knowledge I have gained since then. This remake reflects my growth in front-end development, with cleaner code, improved responsiveness, and a more polished overall design.

Portfolio Layout (Practice Project)

A dark-themed developer portfolio landing page built with HTML, CSS, and JavaScript based on a Figma Make mockup. Created as a front-end practice project, it focuses on translating a complex, multi-section design into code, including a GitHub-style contribution heatmap and a responsive mobile navigation menu. Git was used for version control, and the project is deployed on Vercel.
